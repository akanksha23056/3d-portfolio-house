# Akanksha Ray — 3D Portfolio House

An interactive, scroll-driven 3D portfolio residence built with **React**, **Three.js**, **@react-three/fiber**, and **@react-three/drei**.

## Features
- **Atmospheric Exterior**: Custom GLSL smooth sky dome shader, volumetric drifting clouds, wind streamlines, swaying 3D grass tufts & wildflowers, white picket fence, deep blue tiled roof, see-through windows, and a welcoming front door that smoothly opens on scroll.
- **Kitchen Tour**:
  - **Fridge Magnets (AI Skills)**: Custom 3D fridge magnets and floating labels highlighting **Prompt Engineering (LLM Agents & RAG AI)** and **Multilingual NLP (Hindi & Dialect AI)**.
  - **The Oven**: Rotating 3D **React & Three.js** atomic emblem and floating typography.
- **Living Room Tour**:
  - Plush 3-seater couch and wooden side table with a steaming cup of coffee and an interactive 3D broadsheet newspaper (*The Silicon Chronicle*).
  - **3D Page-Flipping Newspaper**: Zooms into the front page to reveal **VLSI & CMOS IC Design**, then physically flips the 3D page open on scroll to reveal **Embedded C/C++ & RISC-V Architecture**.

## Getting Started

```bash
npm install
npm run dev
```
